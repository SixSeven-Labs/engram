# engram
Session transcripts folded into engrams while you sleep. Recalled as assemblies, not rows. Outcomes remembered as feelings.

- [docs/BACKGROUND.md](docs/BACKGROUND.md): the pieces engram assembles, where each came from, and the design constraints.
- [docs/DESIGN.md](docs/DESIGN.md): every ruling organ by organ, tagged ruled, measured, default, or open. The document the build implements from.
